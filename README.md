# Веб-приложение для построения UML-диаграмм классов

Интерактивный редактор для создания и редактирования UML-диаграмм классов с возможностью совместной работы в реальном времени.

## Технологии

- **React** - построение пользовательского интерфейса
- **JavaScript** - логика приложения
- **SVG** - отрисовка элементов диаграмм без использования внешних библиотек
- **WebSocket** - синхронизация данных между пользователями в реальном времени
- **REST API** - обмен данными с сервером
- **HTML, CSS** - верстка и стилизация

## Функциональность

- Создание и редактирование UML-диаграмм классов (классы, стрелки, связи)
- Совместная работа нескольких пользователей одновременно через WebSocket
- Валидация диаграмм на сервере и отображение ошибок в интерфейсе
- Сохранение и загрузка диаграмм через REST API
